# wubi-analyzer — 五笔补码与笔画分析工具

## 描述

专门用于五笔字型编码体系的分析工具，提供：
1. **补码判断**：判断汉字是否需要末笔识别码（补码），以及对应的识别码键位
2. **笔画查询**：查询汉字总笔画数
3. **字根笔画**：查询指定字根包含的笔画数及笔型序列
4. **完整编码分析**：给出一个汉字的完整五笔编码推导过程

## 激活条件

当用户提出以下类型的问题时，加载此 Skill：
- 「这个字有没有补码」「末笔识别码是什么」
- 「这个字有几笔」「笔画数是多少」
- 「这个字根有几笔」「字根笔画是什么」
- 「五笔编码怎么打」「怎么拆字」「识别码对应哪个键」
- 涉及 wubi-visualizer、wubi-stroke-color-pack 项目的字根/笔画数据验证

## 使用方式

调用脚本：`node scripts/run.js <命令> <参数>`

### 命令列表

```bash
# 分析一个汉字的补码情况
node scripts/run.js identifier 汉

# 查询汉字笔画数
node scripts/run.js strokes 汉

# 查询字根的笔画信息
node scripts/run.js radical 氵

# 完整编码分析（需要提供字根拆分）
node scripts/run.js analyze 汉 氵又

# 查询识别码表
node scripts/run.js table
```

## 工作流程

### 补码判断流程

```
输入汉字
  ↓
是否键名字？→ 是 → 无补码，编码=连按本键4次
  ↓ 否
是否成字字根？→ 是 → 无补码，编码=键名+首笔+次笔
  ↓ 否
是否单笔画？→ 是 → 特殊编码
  ↓ 否
字根数 >= 4？→ 是 → 无补码，取前4根键位
  ↓ 否
字根数 < 4 → 有补码
  ↓
末笔笔型(1-5) × 字型结构(1-3) → 识别码键位
```

### 识别码速查表

| 末笔↓ \ 字型→ | 左右(1) | 上下(2) | 杂合(3) |
|--------------|---------|---------|---------|
| 横(1)        | G(11)   | F(12)   | D(13)   |
| 竖(2)        | H(21)   | J(22)   | K(23)   |
| 撇(3)        | T(31)   | R(32)   | E(33)   |
| 捺(4)        | Y(41)   | U(42)   | I(43)   |
| 折(5)        | N(51)   | B(52)   | V(53)   |

### 末笔特殊规定

- **力、刀、九、匕** 等：末笔为折（5），不是撇
- **我、贱** 等有撇的字：末笔为撇（3）
- **义、太、勺** 等：末笔为点捺（4）
- **廴、辶** 末笔：捺（4）

## 数据来源

- 字根笔画数据：`scripts/radical-stroke-db.js`（与权威字根键位对应表 1:1 对齐，约 250 条）
- 汉字结构数据：基于部首、偏旁位置判断字型（左右/上下/杂合）

### 字根归属约定

1. **双归属字根的取舍**：以下字根在权威表中同时归属两个键，已按用户指定各保留其一：
   - `一` → **G**(11)（A 区条目已删）
   - `龵` → **D**(13)（R 区条目已删）
   - `亻` → **W**(34)（T 区条目已删）
   - `𠤎` → **A**(15)（X 区条目已删）
   - `𠄎` → **N**(51)（E 区条目已删）
2. **单笔画归属**（按权威表）：`一`→G、`丨`→H、`丿`→**Q**、`丶`→Y、`乙`→**N**。
3. **末笔特殊规定**严格执行（补码判断依据）：力/刀/九/匕→折(5)；我/贱→撇(3)；义/太/勺→点捺(4)；廴/辶→捺(4)。
4. **strokeSeq 标注**：末笔(lastStroke)经严格核对；个别 CJK 扩展区部件 / 描述性部件（`[長头]`、`[豸底]` 等）的 strokeSeq 标注为「待核」，如有出入以 lastStroke 为准。

## 注意事项

1. **字根笔画数** 是固定的，依赖 `radical-stroke-db.js` 中的 `RADICAL_STROKES` 表
2. **末笔判断** 需要知道字根拆分顺序，最后一个字根的最后一笔即为末笔
3. **字型判断** 是主观性最强的部分，杂合型包括：包围结构、穿插结构、单体字
4. 汉字总笔画 = 各字根笔画数之和（部分笔画在拆分时可能重复计入，需注意）
